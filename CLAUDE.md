## What this repo is for
A template for breaking a book down one chapter at a time, aimed at adaptation work rather than plain summary. Moby Dick is the worked example ("Or The Vertical Whale" — vertical as in short-form vertical video, which is why the template carries a CINEMATIC IMAGES field).

Template fields, in order: **SUMMARY**, **KEY QUOTES**, **KEY THEMES**, **KEY EVENTS**, **CINEMATIC IMAGES**, **CHARACTERS**, **LOCATIONS**, under a `**BOOK TITLE**` / subtitle heading and a `**Chapter/Episode:**` line.

There is no code here. The "summarizer" is the template plus a model. New chapters belong in this repo as one file per chapter, matching the existing example.
